# Logs

One log per change, named `<trace-ID>-<short-name>.log` (for example `T-004-convert-state-root.log`).

Each log holds, in order: the date and time, the command, its output, and its exit status. The trace ID links the log to its row in `../trace.md`.

These logs are the raw material for the revision guide written after the work is done.
